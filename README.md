# HealthEdPro 💙

This is my project **HealthEdPro** — a mental health platform I built using the MERN stack.  
It's made for anyone who wants to check in on their mental health, get support, and feel less alone.

## 🌱 Why I Made This

I’ve seen people around me struggle with mental health and not know where to start.  
So I thought—what if I make something where people can take simple tests, understand where they stand, and get tools to feel better?

Mental health matters, and this is my small effort toward making support more reachable.

## 🛠️ Tech Stack

- **Frontend**: React.js  
- **Backend**: Node.js + Express  
- **Database**: MongoDB  
- **APIs Used**:
  - Gemini API (for the chatbot)
  - Google Books API (for the mental health library)
  - Custom REST APIs

## ✨ Features

- ✅ Mental health **assessment tests**  
- 🤖 A personal **chatbot** (powered by Gemini)  
- 👥 **Community** section to connect with others  
- 🚨 **Emergency** help/contact section  
- 📚 Mental health **library** (with books pulled from Google Books API)  
- 📝 A helpful **blog** for mental wellness tips and updates  
- 🎯 Simple dashboard to track and explore

## 🚧 Current Status

Still working on improving some parts and adding more features.  
UI needs polishing and chatbot can get smarter — but it's working and live!
